# Skills

Personal Claude Code skills, one per directory (`<name>/SKILL.md`).

- `commit-rules` — commit message rules
- `lazy-dev` — smallest-complete-change coding mode
- `learning` — point to code hot spots to review after implementing

## Install

```sh
ln -s ~/Documents/skills ~/.claude/skills
```

If `~/.claude/skills` already exists, symlink each skill directory into it instead.
